# Тестирование баланса

Экспериментальный TCP-запрос 63 сохраняет отдельный профиль для аккаунта и героя. Main разрешает его только при `Main.Testing.enableBalanceOverrides=true`, вне текущего боя и для принадлежащего игроку героя. Профили сохраняются вместе с аккаунтом в PostgreSQL. Изменения действуют со следующего матча, в том числе в раундах Арены.

HP и урон: 50–200% обычного значения с учётом уровня. Скорость: 75–125%. Три нуля сбрасывают профиль. Неверные значения отклоняются, а не молча обрезаются. Battle повторно проверяет границы внутренних запросов аллокации.

В Unity на объекте Client добавлен компонент `ExperimentalBalanceSettings`: укажи ID героя, проценты и в контекстном меню компонента выбери «Применить баланс на сервере». Делать это после входа, до поиска боя. `ServerStatus` показывает подтверждение сервера или отказ. Публичные методы `Apply` и `ResetBalance` можно привязать к оформленным вручную кнопкам экспериментального билда. Готовый экран доступен в Настройки → ТЕСТ БАЛАНСА: три ползунка, серверное подтверждение, сброс. Он использует выбранного в хабе героя и загружает его сохранённые значения при открытии.

Функция включена в локальном и Docker-конфигах экспериментального сервера; для обычного сервера флаг следует выключить. Оригинальный C#-сервер не поддерживает запрос 63: применять только после подключения к Go.
