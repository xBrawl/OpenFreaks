# OpenFreaks

Go-сервер экспериментального Freaks: main TCP 9609, battle UDP/KCP 9610, PostgreSQL. Бинарь запускается в режимах `all`, `main`, `battle`.

## Запуск через Docker

На Linux: `sh deploy/init-env.sh YOUR_PUBLIC_IP`, затем `docker compose up -d --build`.
На Windows: `./deploy/init-env.ps1 -AdvertisedHost YOUR_PUBLIC_IP`, затем та же команда Compose.
Открыть TCP 9609 и UDP 9610. PostgreSQL и внутренние HTTP 9709/9710 наружу не публикуются. Секреты находятся в `.env`, который нельзя коммитить. Каталог YAML входит в образ.

Для локальной сборки: `go build -o openfreaks.exe ./cmd/openfreaks`.
Задать `XBRAWL_DATABASE_URL` и запустить `./openfreaks.exe --mode=all --config=deploy/config.local.json`.
Main требует PostgreSQL; отсутствие или ошибки каталога в настоящем запуске приводят к отказу старта.

## Реализовано и проверено

- Регистрация, авторизация, кошельки, магазин, прогрессия, история боёв, друзья, кланы, команды.
- Мастерство и диалоги, ежедневный подарок, связи игроков, клановый реактор, пасс и задания.
- Серверная симуляция, препятствия, снаряды, призывы, статусы, рывки, улучшения, 30 усилений; боты с поиском пути и выбором целей.
- Арена: три жизни на команду, выбор усиления между раундами, автоматический выбор при бездействии, восстановление потерянной комнаты без потери жизни.
- Повторы новых Go-боёв, переподключение, устойчивый outbox результатов, повтор неудавшегося выхода из боя.
- Экспериментальные настройки баланса: см. [TEST-BALANCE.md](docs/TEST-BALANCE.md). По умолчанию разрешены в экспериментальных local/Docker-конфигах.

Операции аккаунтов подтверждаются после записи PostgreSQL. Миграции 1–5 совместимы с исходной схемой, 6–7 добавляют полный checkpoint и защиту от двух одновременных main-писателей. Нельзя одновременно запускать C# и Go main на одной базе. После новых записей Go обратный переход на C# требует переноса новых данных или восстановления резервной копии; простого переключения бинарника недостаточно.

## Проверки и ограничения

`go test ./...` и `go test -race ./...` проверяют Go-пакеты. Интеграционные PostgreSQL-тесты требуют отдельной тестовой БД; не указывать рабочую.
Для внешнего smoke: `OPENFREAKS_SMOKE_MAIN=127.0.0.1:9609 go test ./internal/mainserver -run '^TestSmokeFullFlow$' -count=1` (создаёт тестовый аккаунт и бой).

На 20 сентября 2026 Go установлен на VDS `85.137.89.21`: TCP9609, UDP9610; systemd `openfreaks-main` и `openfreaks-battle`. Старые C#-службы остановлены и отключены. Go использует отдельную копию базы `openfreaks_live_20260920`; исходная база сохранена. Резервная копия до переключения: `/root/freaks-final-csharp-20260920.dump` (секретная, только на VDS).

Футбол доступен через выбор локации: 3×3, два гола, 150 секунд + 60 секунд овертайма при ничьей, супер-удар за заряд ульты, броски вместо обычной атаки, отскок от стен, проход с мячом в ворота. Навыки без мяча работают обычным образом, рывки с мячом помогают продвигаться. Карта экспериментальная.

Тестовая арена: две постоянные комнаты по 10 мест, автоматический выбор свободного места, все против всех, возрождение через 5 секунд, без наград. Комната не заканчивается по таймеру; при перезапуске battle создаётся заново. При потере UDP слот освобождается примерно через 15 секунд. Вход и выход — стандартными кнопками клиента.

«МЕГАБОСС»: локация `mega_boss_karity`, режим `mega_boss`. Очередь длится 60 секунд и запускает бой только с 3–6 людьми; при нехватке игроков поиск отменяется. Ботов-добивок нет, Карити добавляется как единственный серверный противник. Бой длится до 3 минут и заканчивается сразу после гибели босса. HP Карити в этом режиме: 145 000 при трёх игроках, пропорционально до 290 000 при шести. За победу каждому не покинувшему бой игроку начисляются 500 каритов и 20 жетонов улучшения; трофеи не меняются. Результат идемпотентен. Выбор босса привязан к дню UTC; пока в ротации только Карити. Экспериментальные множители характеристик в этом наградном режиме отключены.

Экран баланса: Настройки → ТЕСТ БАЛАНСА. Выбранный в хабе герой, три ползунка, серверное сохранение и сброс. В standalone/Android включён define FREAKS_EXPERIMENTAL, поэтому экспериментальный билд использует VDS и без Development Build. Для официального production-клиента этот define применять нельзя.

Реклама, реальные покупки и voice relay не подключены. Откат на C# после новых Go-боёв не перенесёт новый прогресс автоматически: сначала сохранить Go-базу. Полный журнал: [IMPLEMENTATION-20260920.md](docs/IMPLEMENTATION-20260920.md).

## WebSocket

Go supports binary WebSocket main/battle channels, deployed behind WSS on VDS. Protocol and Unity integration contract: [WEB-TRANSPORT.md](docs/WEB-TRANSPORT.md). This does not by itself make the current Unity client WebGL-ready.

## Приглашение и сборки

Регистрация требует `VERITYINFREAKS`; вход существующих аккаунтов не требует кода. Android-название `Freaks Experimental`, package `com.xsoft.xbrawl.experimental`, отдельная TEST-иконка. APK пока не получен: команда Unity build возвращает timeout при idle-статусе. WebGL-модуль установлен; клиентский WSS-мост, WebGL-бандлы и публикация страницы игры ещё не выполнены.
